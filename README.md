## Nasıl Kurulur?
* [Releases](https://github.com/nursezakarakaya/Cutecore-Notepad/releases) sayfasından son versiyonu indirip içindeki `NotDefteri.exe` dosyasını çalıştırmanız yeterli.

*Not: Windows ilk açılışta SmartScreen uyarısı verebilir. Uygulamanın kaynak kodları tamamen açıktır ve hiçbir şekilde içinde herhangi bir zararlı veya casus yazılım barındırmamaktadır. Gelen pencerede 'Ek bilgi -> Yine de çalıştır' diyerek güvenle kullanabilirsiniz.*
* **Visual Studio üzerinden** kaynak kodu açmak isterseniz bu repo'yu indirip `NotDefteri.slnx` solution dosyasını çalıştırın.
